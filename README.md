# Rajeshwari Shinde - Full Stack Java Developer Portfolio

A premium, modern, and responsive portfolio website built with React, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Modern UI/UX**: Minimal, elegant design with glassmorphism cards and soft shadows
- **Premium Theme**: Black, white, beige with subtle gold accent colors
- **Dark/Light Mode**: Toggle between dark and light themes
- **Smooth Animations**: Framer Motion animations with scroll reveal effects
- **Interactive Elements**: Hover effects, floating icons, and gradient cursor glow
- **Responsive Design**: Mobile-first approach that works on all devices
- **SEO Optimized**: Semantic HTML and meta tags for better search visibility
- **Fast Performance**: Optimized for speed with lazy loading

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Scroll**: React Scroll
- **Fonts**: Poppins & Playfair Display (Google Fonts)

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/rajeshwarishinde16/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000`

## 🏗️ Build for Production

```bash
npm run build
```

The optimized build will be in the `dist` folder.

## 🎨 Customization

### Colors
Edit `tailwind.config.js` to customize the color scheme:

```javascript
colors: {
  primary: {
    black: '#0a0a0a',
    white: '#ffffff',
    beige: '#f5f0e8',
    gold: '#d4af37',
    goldLight: '#f4d03f',
    gray: '#6b7280',
  },
}
```

### Content
Update the content in each component file to personalize your portfolio:
- Personal information in `Hero.jsx`
- About section in `About.jsx`
- Services in `Services.jsx`
- Skills in `Skills.jsx`
- Projects in `Projects.jsx`
- Contact information in `Contact.jsx`
